About

Tentang website Control : BIT dan tim di baliknya.

Apa itu Control : BIT?

Control : BIT adalah dashboard berbasis web yang memungkinkan kamu menghubungkan, memantau, dan mengendalikan board BBC micro:bit langsung dari browser lewat Bluetooth (Web Bluetooth API / Nordic UART Service) — tanpa perlu install aplikasi tambahan apa pun.

Bisa dipakai untuk apa?

📊
Dashboard
Memantau data sensor (suhu, kelembaban) secara real-time dan mengontrol output seperti lampu, mode, dan kipas.
🕹️
Bluetooth Controller
Mengirim sinyal arah (atas/bawah/kiri/kanan) ke micro:bit, lengkap dengan berbagai tema tombol yang seru.
🕓
History Activities
Mencatat semua data yang diterima dan perintah yang dikirim, supaya mudah ditelusuri kembali.
⚙️
Settings
Mengatur bahasa, mode terang/gelap, dan tema warna sesuai selera kamu.
